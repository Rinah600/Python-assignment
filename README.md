# Shared Expense Tracker

A Python CLI project for tracking expenses shared equally
between two people.

## Planned features

- Add and view expenses.
- Show spending totals.
- Calculate who owes whom.
- Save and load expenses using JSON.

## Rules

- Two participants.
- Currency: UGX.
- Every expense is split equally.
- Input amounts must be positive whole numbers.

## Status

Project structure created. Implementation has not started.
