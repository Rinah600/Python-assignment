# Shared Expense Tracker

A Python CLI application that helps two people record shared expenses and calculate who owes whom.

## Features

- Add and view expenses.
- Show totals by person and category.
- Calculate an equal split.
- Save and load expenses using JSON.

## Project Files

- main.py — Menu and user input.
- models.py — Expense class.
- tracker.py — Expense management and calculations.
- storage.py — Saving and loading data.

## Rules

- Two participants.
- Currency: UGX.
- Expenses are split equally.
- Amounts must be positive whole numbers.
